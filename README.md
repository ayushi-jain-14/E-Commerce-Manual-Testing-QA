# E-Commerce-Manual-Testing-QA
## Project Overview

This project demonstrates manual testing of an E-Commerce web application using Jira and Excel.

The project covers functional testing of user registration, login, product search, product details, shopping cart, wishlist, checkout, payment, and order confirmation.

## Testing Scope

- User Registration & Login
- Product Search & Product Details
- Shopping Cart & Wishlist
- Checkout & Payment
- Order Confirmation

## Tools Used

- Jira
- Microsoft Excel
- GitHub
- Manual Testing
