# E-Commerce-Manual-Testing-QA
## Project Overview

This project demonstrates manual testing of an E-Commerce web application using Jira and Excel.

The project covers functional testing of user registration, login, product search, product details, shopping cart, wishlist, checkout, payment, and order confirmation.

## Testing Scope

- User Registration & Login
- Product Search & Product Details
- Shopping Cart & Wishlist
- Checkout & Payment
- Order Confirmation

## Tools Used

- Jira
- Microsoft Excel
- GitHub
- Manual Testing
  
## Test Deliverables

- Test Scenarios
- Test Cases
- Test Execution Results
- Test Summary
- Defect Summary
- Jira Defect Tracking
- Final Test Report

## Defects

During testing, defects were identified and documented in Jira with proper steps to reproduce, expected result, actual result, and severity/priority details.

## Project Status

**Testing Completed**

The major E-Commerce application modules were manually tested and the test execution results were documented in Excel.
